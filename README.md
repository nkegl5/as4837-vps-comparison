## 购买前最好自己做一次线路验收

尤其是你准备拿 VPS 做正式业务，而不是单纯做临时测试，建议把验收流程做完整一点。

### 1. 先确认实际测试IP

让商家提供与准备购买的城市、产品线尽可能一致的测试 IP。不要拿另一个节点、另一条线路的测试结果替代。

### 2. 分别测试电信、联通、移动

至少做 `ping`、`traceroute` 或 `mtr`。不要因为你是联通用户，就默认电信和移动也会得到相同结果。

### 3. 看高峰期，不只看白天

如果你最常用服务器的时间是晚上，那就应该在晚上测。网络拥塞是动态的，白天跑得很漂亮，并不能自动推出晚上也一样。

### 4. 测持续吞吐，不只看瞬时峰值

300Mbps 或 500Mbps 是规格，不是对任意来源、任意时间段的永久吞吐保证。测试文件下载、上传以及真实应用访问，更接近实际使用。

### 5. 测你真正依赖的平台

如果你的核心需求是美国流媒体、社媒、电商后台或特定 SaaS，就直接测试这些服务。IP 的“住宅属性”与某个平台是否接受，是两个相关但不同的问题。

专门研究美国 AS4837 VPS 的测试资料也建议结合双向路由、连续高峰测试、真实应用和最终服务器表现，而不是只看某一个中间跳点。
